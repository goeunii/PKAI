# 프로젝트 제안서

## 1. 프로젝트명

**공장 생산데이터 기반 피크전력 예측 및 생산일정 최적화**

부제:

> 중소 제조기업을 위한 다음 날 전력위험 예측과 생산량 재배치 시스템

---

## 2. 해결하려는 문제

중소 제조기업은 생산설비를 여러 대 동시에 가동하면서 특정 시간대에 전력사용량이 크게 증가할 수 있다.

전력피크가 높아지면 다음 문제가 발생한다.

- 최대수요전력 증가
- 전력비용 증가
- 설비부하 집중
- 생산운영 안정성 저하
- 급격한 생산량 변화에 따른 예측 실패

하지만 중소기업은 기계별 전력센서나 정교한 에너지관리시스템이 없는 경우가 많다.

본 프로젝트에서는 공장 전체의 생산량과 전력데이터만 사용해 다음 날 전력을 예측하고, 전력피크가 낮아지도록 시간대별 생산량을 조정한다.

---

## 3. 핵심 아이디어

본 프로젝트는 다음 세 가지를 함께 수행한다.

1. 다음 날 24시간의 평균전력을 예측한다.
2. 각 시간의 15분 최대전력과 피크위험을 예측한다.
3. 하루 총생산량을 유지하면서 생산량을 다른 시간대로 옮긴다.

전체 흐름은 다음과 같다.

```text
생산·전력 데이터
        ↓
결측치·시간 오류 처리
        ↓
다음 날 평균전력과 15분 최대전력 예측
        ↓
P50·P90을 이용한 피크위험 계산
        ↓
위험시간의 생산량을 여유시간으로 이동
        ↓
변경된 생산계획의 전력을 다시 예측
        ↓
변경 전·후 피크와 비용 비교
```

---

## 4. 제조환경 정의

본 연구는 대형 공장 전체가 아니라, 공장 안에서 비슷한 생산설비가 여러 대 운영되는 하나의 핵심 작업구역을 대상으로 한다.

예시는 다음과 같다.

- 자동차부품 가공설비
- 사출성형기
- CNC 가공기
- 프레스 설비
- 포장·충전 설비
- 반도체 검사설비

기계 수와 기계별 데이터는 제공되지 않았으므로, 핵심 모델은 공장 전체의 시간대별 생산량을 조정한다.

필요한 경우 현장 적용 예시로 5대의 유사 병렬설비를 가정한다. 단, 5대는 데이터에서 발견된 사실이 아니라 제안 방법을 설명하기 위한 기준 시나리오다.

---

## 5. 데이터 정의

한 행은 하루의 특정 시간대를 나타낸다.

주요 변수는 다음과 같다.

| 변수              | 사용 목적                     |
| --------------- | ------------------------- |
| 날짜·시간           | 시간 순서와 계절정보               |
| 15분·30분·45분·60분 | 시간 안의 15분 간격 전력값          |
| 평균              | 네 전력값의 평균                 |
| 생산량             | 시간대별 생산량                  |
| 기온·풍속·습도·강수량    | 날씨에 따른 전력변화               |
| 전기요금(계절)        | 계절별 비용 가중치                |
| 공장인원            | 생산에 필요한 인력지표로 추정          |
| 인건비             | 정상시간 1, 비정상시간 1.5의 비용 가중치 |

전력과 생산량의 실제 단위는 제공되지 않았다. 따라서 결과는 kW나 원이 아니라 전력지표, 비용지표, 감소율로 표현한다.

## 6. 전처리 원칙

### 결측치

- 풍속 3건: 시간 순서에 따른 선형보간
- 강수량 1건: 같은 날짜의 주변값을 고려해 0으로 처리
- 공장인원 17건: 해당 구간의 생산량이 모두 0이므로 0으로 처리
- 원래 결측이었던 행을 표시하는 결측 플래그 추가

### 시간 오류

2021년 7월 13일과 15일의 시간값이 0～23 범위를 벗어난다.

두 날짜는 다음 방법을 비교한다.

- 두 날짜 제외
- 행 순서에 따라 시간을 0～23으로 복원

두 처리 결과가 크게 다르지 않은지 확인한다.

### 데이터 누출 방지

`평균`은 같은 행의 15분·30분·45분·60분 값으로 계산된다.

따라서 평균을 예측할 때 같은 시간의 네 전력값을 입력으로 사용하지 않는다. 예측 시점보다 이전에 알 수 있는 정보만 사용한다.

---

## 7. 예측 시점과 목표

### 예측 시점

전날 생산계획을 세우는 시점에 다음 날 24시간을 예측한다.

예:

```text
오늘까지의 데이터 + 내일 생산계획
→ 내일 00시부터 23시까지의 전력 예측
```

### 예측 목표 1: 시간 평균전력

```python
평균전력 = 평균
```

전체적인 전력사용 흐름을 예측한다.

### 예측 목표 2: 시간 내 15분 최대전력

```python
15분_최대전력 = max(15분, 30분, 45분, 60분)
```

시간 평균은 낮지만 중간에 전력이 급격하게 상승하는 상황을 찾기 위해 사용한다.

## 8. P50과 P90의 의미

일반적인 예측모델은 예상값 하나만 출력한다. 하지만 예측은 항상 틀릴 수 있다.

본 프로젝트는 P50과 P90을 함께 예측한다.

### P50

가장 일반적으로 예상되는 전력값이다.

예:

```text
14시 P50 = 180
```

14시 전력을 보통 180 정도로 예상한다는 의미다.

### P90

예측오차까지 고려한 보수적인 전력 상한이다.

예:

```text
14시 P90 = 205
```

대부분의 상황에서 실제 전력이 205보다 낮을 것으로 예상한다는 의미다.

생산일정 최적화에는 P50보다 P90을 사용한다.

```text
P50 기준: 평소 상황에 유리
P90 기준: 예상보다 전력이 높아지는 상황에도 안전
```

## 9. 예측모델 계획

### 비교할 모델

1. 전날 같은 시간의 전력을 사용하는 단순모델
2. 선형회귀 또는 Random Forest
3. LightGBM

LightGBM을 최종 후보로 사용한다.

데이터가 약 6천 행이므로 복잡한 딥러닝보다 트리 기반 모델을 우선한다.

### 주요 입력변수

- 1·2·3·24·168시간 전 전력
- 전날 같은 시간의 전력
- 최근 전력 이동평균
- 내일 시간대별 생산계획
- 생산량 변화량
- 시간·요일·월
- 기온·습도·풍속·강수량
- 전기요금 가중치
- 인건비 가중치

미래 날씨는 원칙적으로 일기예보를 사용해야 한다. 현재 데이터에는 예보값이 없으므로 실제 기상값을 예보값으로 가정한 실험임을 한계로 밝힌다.

## 10. 데이터 분할

데이터를 무작위로 섞지 않고 시간순으로 나눈다.

예시:

```text
학습: 2021년 1월～6월
검증: 2021년 7월～8월
최종시험: 2021년 9월 1일～14일
```

과거 데이터로 학습하고 이후 기간을 예측해야 실제 운영상황과 비슷하다.

## 11. 예측 성능 평가

### 평균전력 평가

- MAE: 평균적으로 얼마나 틀렸는지
- RMSE: 큰 오차에 더 큰 벌점을 주는 지표
- WAPE: 전체 전력 규모와 비교한 오차비율

### 피크 예측 평가

- 15분 최대전력 MAE
- 실제 피크시간과 예측 피크시간의 차이
- 상위 5% 고전력 구간의 오차
- 피크위험 재현율
- P90이 실제값을 포함한 비율

### 조건별 오류분석

다음 상황에서 오차가 커지는지 확인한다.

- 생산량 급증·급감
- 생산 시작과 종료
- 주간·야간
- 평일·주말
- 고온·고습
- 강수
- 계절
- 전력피크 구간

## 12. 생산일정 최적화

최적화는 시간대별 생산량을 결정한다.

### 지켜야 하는 조건

- 하루 총생산량 유지
- 시간당 최대생산량 준수
- 생산량을 음수로 설정할 수 없음
- 한 시간의 생산량을 지나치게 많이 변경하지 않음
- 가능한 경우 같은 근무시간 안에서 이동
- 야간생산 시 인건비 가중치 1.5 적용
- 과거에 관측되지 않은 비현실적인 생산량 금지

### 최소화할 대상

- P90 최대전력
- 요금가중 전력비용
- 인건비 가중비용
- 기존 생산계획과의 차이

쉽게 표현하면 다음과 같다.

> 생산량은 그대로 유지하면서 전력이 몰리는 시간의 생산을 여유시간으로 조금씩 옮긴다. 단, 야간작업과 지나친 일정변경에는 비용을 부여한다.

## 13. 비교할 생산정책

| 정책      | 설명                      |
| ------- | ----------------------- |
| 기존 일정   | 생산량을 이동하지 않음            |
| 단순 분산   | 가장 바쁜 시간의 생산을 빈 시간으로 이동 |
| P50 최적화 | 일반적인 예상전력을 기준으로 이동      |
| P90 최적화 | 예측오차까지 고려한 안전한 일정 생성    |

최종적으로 다음을 비교한다.

- 최대피크 감소율
- 피크 초과시간 수
- 요금가중 비용 변화
- 인건비 변화
- 이동된 생산량 비율
- 하루 총생산량 보존 여부

최적화에 따른 절감효과는 실제 현장실험 결과가 아니라 예측모델 기반 시뮬레이션 결과라고 밝힌다.

## 14. 병렬기계 시나리오

시간이 남으면 5대의 유사 병렬설비를 가진 생산 셀을 추가로 가정한다.

최적화가 결정하는 항목:

- 시간대별 가동 설비 수
- 설비별 생산량
- 설비의 RUN·IDLE·SLEEP·OFF 상태
- 설비 정지와 재기동 시점

주의사항:

- 5대는 데이터에서 확인된 수가 아님
- 3대만 가동하는 것을 미리 정답으로 설정하지 않음
- 3대·5대·8대 환경을 비교
- 재기동에너지와 준비시간을 바꿔 민감도 분석

이 부분은 핵심 모델이 아니라 현장 적용 가능성을 설명하는 확장 실험으로 사용한다.

## 15. 참고 연구

병렬기계 스케줄링 구조는 다음 연구를 참고한다.

- Sung-Ho Min, Sang-Wook Lee, Hyun Jung Kim, *Parallel Machine Scheduling With Peak Energy Consumption Limits*, IEEE Transactions on Automation Science and Engineering.
- 논문 링크: [https://ieeexplore.ieee.org/document/10443429/](https://ieeexplore.ieee.org/document/10443429/)

참고한 부분:

- 여러 병렬설비에 작업을 배정하는 구조
- 동시가동 전력의 피크 제한
- 유휴설비의 전력소비 고려
- 대규모 문제를 위한 휴리스틱 최적화

본 프로젝트의 차이점:

- 작업별 전력이 주어진다고 가정하지 않고 제조데이터로 전력을 예측
- 하나의 예상값이 아니라 P50·P90 예측
- 생산량, 계절요금과 인건비를 함께 고려
- 기계별 데이터가 없어 공장 집계 생산량 수준에서 먼저 최적화
- 논문의 모델을 그대로 복제하지 않고 중소 제조환경에 맞게 단순화

## 16. 프로젝트의 차별성

1. 시간 평균전력과 15분 최대전력을 함께 예측한다.
2. 예측오차를 고려한 P90 피크위험을 사용한다.
3. 예측 결과를 실제 생산일정 변경으로 연결한다.
4. 기계별 센서가 없어도 공장 집계데이터만으로 실행할 수 있다.
5. 단순 분산, P50 최적화, P90 최적화를 동일한 조건에서 비교한다.
6. 데이터에서 확인된 사실과 팀이 설정한 가정을 구분한다.
